# ULEM – Perbaikan Sampul

Paket ini memperbaiki pembuka undangan agar berjalan konsisten di HP dan desktop.

- Menghapus skrip pembuka lama yang hanya berada pada widget tersembunyi untuk desktop.
- Menambahkan tombol Buka Undangan yang benar-benar tersedia di HTML.
- Mengunci scroll hanya saat sampul tampil, lalu memulihkannya saat tombol ditekan.
- Menormalkan posisi sampul agar memenuhi layar, menghapus ukuran/offset sticky lama.
- Membekukan satu slide foto pertama agar Swiper tidak berkedip atau berpindah otomatis.
- Mengganti ID sticky spacer duplikat.

Unggah `index.html` dan folder `aset/` ke root repository GitHub Pages. Pertahankan seluruh aset.
